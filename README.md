# Jungah Kim — Academic Portfolio

The source repository for Jungah Kim's academic portfolio, published with GitHub Pages.

## Live site

**https://jungalatte92.github.io/jungah-academic-page/**

## About

Jungah Kim is a Victorianist and Marion L. Brittain Postdoctoral Fellow at the Georgia Institute of Technology. Her scholarship brings together nineteenth-century British literature, East Asian cultural history, material culture, transimperial translation, and digital humanities.

The website presents:

- current research and book projects;
- selected peer-reviewed publications;
- teaching in literature, writing, and technical communication;
- the New York Subway digital humanities project; and
- links to her CV, academic website, and contact information.

## Publishing

GitHub Pages publishes the site from the `main` branch and repository root. Updates pushed to `main` are reflected at the live URL after the Pages deployment completes.
